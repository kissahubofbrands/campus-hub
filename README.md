# 🎓 CampusConnect

### One Platform. Every College Update.

CampusConnect is a centralized college communication platform designed to solve the problem of students missing important information because announcements are shared through different communication channels.

The platform brings **announcements, events, deadlines, notifications, and daily timetables** together in one place.

---

## 🚨 Problem Statement

Students often receive college information through multiple channels such as:

- WhatsApp groups
- Email
- Notice boards
- Class groups
- Verbal announcements
- Different department platforms

Because information is scattered across different mediums, students may:

- Miss important announcements
- Forget upcoming deadlines
- Miss college events
- Not receive timetable changes on time
- Receive outdated information
- Have difficulty finding important updates

---

## 💡 Our Solution

**CampusConnect** provides a single centralized platform where college management can publish information and students can access everything from one dashboard.

### Management → CampusConnect → Students

Management can publish:

📢 Announcements  
📅 Events  
⏰ Deadlines  
🕐 Timetable Updates  
🔔 Notifications  

Students can view all updates through a single dashboard.

---

## ✨ Key Features

### 👨‍🎓 Student Dashboard

- View latest announcements
- View today's timetable
- View upcoming events
- Track important deadlines
- Receive notifications
- Search for information
- Access all college updates from one place

### 👨‍💼 Management Dashboard

- Post announcements
- Add upcoming events
- Create deadlines
- Update timetable
- Manage student communication
- Monitor information delivery

### 🔐 Login System

The prototype provides separate access for:

- Student
- Management / Admin
